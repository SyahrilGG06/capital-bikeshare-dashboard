# Capital Bikeshare Dashboard

Dashboard Streamlit untuk melihat pola sewa sepeda pada hari kerja dan hari nonkerja di Washington D.C. selama 2011 dan 2012. Jalankan dari akar repositori dengan perintah berikut.

    python -m pip install -r requirements.txt
    python -m streamlit run dashboard/dashboard.py

Sumber dan atribusi dataset tersedia di data/Readme.txt.
